# Portfolio - Ilyes Chouiter

Portfolio professionnel pour un étudiant en informatique spécialisé en cybersécurité.

## Structure

```
Portfolio/
├── index.html          # Page principale
├── README.md           # Ce fichier
├── .gitignore          # Fichiers à ignorer
├── css/
│   └── style.css      # Styles CSS
├── js/
│   └── main.js        # JavaScript
└── assets/
    ├── cv/
    │   └── CHOUITER-Ilyes-cv.pdf
    └── images/         # Pour vos images
```

## Déploiement

### Local
Ouvrir `index.html` dans un navigateur.

### Vercel
1. Installer Vercel CLI: `npm install -g vercel`
2. Dans le dossier Portfolio: `vercel`
3. Suivre les instructions

### Netlify
Glisser-déposer le dossier sur https://app.netlify.com/drop

## Personnalisation

### Modifier le contenu
Ouvrir `index.html` et modifier:
- Les sections dans `<section id="...">`
- Les informations personnelles (nom, âge, contact)
- Les projets dans `#projects`
- Les compétences dans `#skills`
- L'expérience dans `#experience`

### Modifier les styles
Ouvrir `css/style.css` et modifier les variables CSS en haut du fichier.

### Ajouter des images
Placer les images dans `assets/images/` et mettre à jour les chemins dans `index.html`.

## Fonctionnalités

- Design responsive (mobile, tablette, desktop)
- Menu mobile
- Typing effect sur la page d'accueil
- Animations au scroll
- Formulaire de contact
- Bouton "Retour en haut"
- Thème sombre par défaut
